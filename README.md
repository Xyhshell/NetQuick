# 网络切换器 V0.5

Windows 平台的网络配置管理与诊断工具。用于在多网络环境之间切换网卡参数，并提供网段扫描、延迟检测、下载测速等辅助功能。

---

## 一、功能概览

### 1. 网卡配置管理

- 自动枚举系统全部网络接口，包括被禁用的接口
- 显示接口名与设备描述（如 `以太网 3 （Realtek USB GbE Family Controller）`）
- 读取并显示当前 IP、子网掩码、默认网关、DNS
- 支持静态 IP 配置与 DHCP 自动获取的相互切换
- 支持启用 / 禁用网卡

### 2. 配置持久化

- 将常用网络配置保存到本地，按名称索引
- 配置包含网卡、IP、掩码、网关、DNS 字段
- 支持载入到表单、直接应用、覆盖、删除
- 存储位置：`%USERPROFILE%\.net_switcher\configs.json`

### 3. 备份与回滚

- 每次应用配置前自动记录当前状态
- 每个网卡维护独立的备份栈，保留最近 5 份
- 应用失败时弹出回滚选项
- 支持手动回滚到最近一次备份
- 存储位置：`%USERPROFILE%\.net_switcher\backups.json`

### 4. 批量操作

- 通过勾选对话框选取多块网卡
- 将同一份配置批量应用到选中的网卡
- 批量恢复 DHCP
- 多网卡使用相同 IP 会产生冲突，需在确认对话框中明确

### 5. 网段扫描

- 扫描范围输入支持四种格式：
  - 单个 IP：`192.168.1.5`
  - 简写区间：`192.168.1.1-100`
  - 完整区间：`192.168.1.1-192.168.1.254`
  - CIDR：`192.168.1.0/24`
- 端口输入支持范围语法：`22,80-88,3306`，单次展开上限 1024 个端口
- 内置 45 个常用端口及服务名映射（如 `22(SSH)`、`445(SMB)`）
- 探测方式为 ICMP + TCP 双判定
- 结果展示 IP、MAC、厂商、主机名、设备类型、开放端口
- 支持点击列头排序、右键复制单元格内容
- 可选显示 ARP 表中未响应设备（默认关闭）

### 6. 延迟检测

- 检测对象：网关、首选 DNS、公网 DNS
- 探测序列为 ICMP → DNS 查询 → TCP 回退
- 输出最小 / 平均 / 最大延迟与丢包率

### 7. 下载测速

- 区域分类：国内 / 国外 / 内网 / 自定义
- 国内源含阿里云、腾讯云、华为云、网易、南大、中科大、清华
- 国外源含 Cloudflare、Hetzner、Tele2、OVH
- 多线程下载（默认 16 线程），采样 10 秒，丢弃前 3 秒慢启动
- 使用 `time.monotonic()` 计时，避免系统校时干扰
- 采用 90 分位稳健峰值与 IQR 稳定性评估
- 内网测速自动从网关和同网段常用地址推导候选源

### 8. 实时网速

- 主界面持续显示全接口的实时上行 / 下行速率
- 数据来源优先级：`GetIfTable2` API → `netstat -e` 回退

### 9. 网络中心快捷入口

- 主界面提供按钮直接打开系统「网络连接」窗口（`ncpa.cpl`）

## 二、兼容性设计

### 网卡名称处理

Windows 下部分网卡（尤其是 USB 外置网卡）的接口名包含空格、中文、`#`、`&`、括号等字符。程序采用以下措施保证命令执行成功：

1. `netsh` 命令的 `name` 参数不使用字面引号，交由 `subprocess` 处理转义
2. 接口名进入命令前进行规范化：去除首尾空白、控制字符、全角空格
3. `netsh` 执行失败时回退到 PowerShell 的 `*-NetIPAddress` / `Set-DnsClientServerAddress` 命令族，后者对特殊字符的兼容性更好
4. PowerShell 内部使用单引号字符串，仅需转义 `'` 字符

### 权限要求

- 读取类操作（网卡列表、当前配置、扫描）无需管理员权限
- 修改类操作（设置 IP、切换 DHCP、禁用网卡）需要管理员权限
- 程序启动时若未以管理员身份运行，会主动提示提权

## 三、模块结构

```
net_switcher/
├── main.py               启动器，处理 sys.path 与运行环境
├── constants.py          常量：DNS 列表、掩码表、测速源、端口映射
├── oui.py                MAC OUI 厂商数据库
├── netutils.py           Windows API 封装、子进程工具、IP/掩码工具
├── interfaces.py         网卡枚举、配置读写、netsh/PowerShell 命令构建
├── scanner.py            网段扫描、端口解析、设备类型识别
├── diagnostics.py        延迟检测、下载测速
├── backup.py             网卡配置备份栈
├── config_store.py       用户配置持久化
├── icon.py               程序图标生成
├── scan_dialog.py        网段扫描窗口
├── batch_dialog.py       批量选择网卡窗口
└── main_app.py           主界面
```

模块依赖方向自下而上：`constants` / `oui` → `netutils` → `interfaces` / `scanner` / `diagnostics` / `backup` / `config_store` → `scan_dialog` / `batch_dialog` → `main_app`。

## 五、运行方式

### 从源码运行

```bash
cd net_switcher
python main.py
```

启动器会自动将当前目录加入 `sys.path`，兼容以下目录布局：

- `main.py` 与其它模块同级
- `main.py` 在外层，`net_switcher/` 为子目录

### 打包为可执行文件

**命令行方式：**

```bash
cd net_switcher
pyinstaller --noconfirm --onefile --windowed ^
    --name NetQuick ^
    --paths . ^
    main.py
```

`--paths .` 用于告知 PyInstaller 模块搜索路径。调试阶段可去掉 `--windowed`，改用 `--console` 以查看启动时的异常输出。

**spec 方式（可选）：**

在 `net_switcher/` 下建立 `NetQuick.spec`，将 `pathex=["."]` 与 `hiddenimports` 显式列出所有平级模块，再执行：

```bash
pyinstaller --noconfirm NetQuick.spec
```

## 六、操作说明

### 切换网卡配置

1. 顶部下拉框选择目标网卡，程序自动读取当前配置
2. 修改 IP、掩码、网关、DNS 字段
3. 点击「应用设置」，确认后执行

掩码字段支持两种输入：

- 十进制位数，如 `24`
- 点分格式，如 `255.255.255.0`

输入后右侧会显示前缀长度。DNS 字段支持下拉历史值与前缀筛选补全。

### 恢复 DHCP

- 「当前网卡开启 DHCP」：仅对下拉框中选中的网卡执行
- 「所有网卡重置为 DHCP」：对系统全部网卡执行

### 保存与复用配置

1. 在「配置列表」区填写配置名
2. 点击「保存当前参数」
3. 后续可通过「一键应用」或双击列表项直接生效

「覆盖选中」用于更新已有配置的字段值，名称保持不变。

### 批量应用

1. 点击「网卡批量选择」
2. 在对话框中勾选目标网卡
3. 顶部按钮变为「批量(N)」
4. 在表单中填写模板参数，点击「应用设置」

批量应用会为每块网卡生成独立的备份记录。

### 扫描网段

1. 点击「扫描网段」
2. 输入扫描范围（支持四种格式）
3. 输入探测端口（支持范围语法）
4. 设置超时与并发数
5. 点击「开始扫描」

扫描过程中可随时停止。结果按扫描顺序插入，点击列头可按任意字段排序。默认只显示 ping 通或有开放端口的主机。

### 延迟与测速

- 延迟检测：点击「开始检测」，依次测量网关、DNS、公网地址
- 下载测速：选择区域与源，点击「开始测速」；内网与自定义模式需填写下载地址

## 七、数据文件

| 文件 | 内容 | 说明 |
|------|------|------|
| `~/.net_switcher/configs.json` | 用户保存的配置列表 | 可手工编辑，格式为 JSON |

## 八、已知限制

- **仅支持 IPv4**：程序未处理 IPv6 地址配置
- **仅支持 Windows**：网卡枚举依赖 `GetIfTable2`，配置写入依赖 `netsh` 与 PowerShell
- **多网卡相同 IP**：批量应用相同 IP 到多块网卡会导致地址冲突，程序在确认对话框中给出提示但不做技术拦截
- **自动获取地址回滚**：DHCP 模式下回滚会重新发起地址申请，获得的地址可能与备份时不同，这是 DHCP 的固有行为
- **端口范围**：单次扫描的端口展开数量上限为 1024，避免误输入 `1-65535` 拖垮扫描

## 九、故障排查

| 现象 | 排查方向 |
|------|----------|
| 启动报 `ModuleNotFoundError` | 确认 `main.py` 与模块目录关系；使用仓库提供的启动器 |
| 网卡列表为空 | 确认是否以管理员身份运行；`netsh interface show interface` 是否有输出 |
| 应用配置失败 | 查看错误弹窗内容；程序会保留 netsh 与 PowerShell 两侧的原始错误信息 |
| 配置应用到含空格名称的网卡失败 | 该场景已通过 PowerShell 回退兼容，如仍失败请提交网卡的完整名称 |
| 扫描结果数量与路由器不一致 | 默认只显示 ping 通或有开放端口的主机；如需包含 ARP 表中的静默设备，请勾选相应选项 |
| 测速结果偏低 | 更换测速源；内网测速需确认目标文件足够大（建议 ≥ 500 MB） |
